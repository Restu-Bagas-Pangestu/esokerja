Tentang lowongan

PTC mencari analis perencanaan dan penjadwalan lapangan untuk proyek di Kilang Pertamina Balikpapan, berstatus kontrak alih daya. Peran ini mengurus jadwal/project control dan berkoordinasi lintas fungsi; pengalaman fase konstruksi, verifikasi TKDN, dan Primavera P6 menjadi nilai tambah.

Kualifikasi

  • Minimal S1 Teknik
  • Pengalaman minimal 3 tahun sebagai scheduler atau project control
  • Diutamakan: pengalaman analis field planning & scheduling, verifikasi/pelaporan TKDN, paham proses pengadaan, fase konstruksi proyek
  • Menguasai Primavera P6 (nilai tambah)
  • Mampu bekerja mandiri dan berkoordinasi dengan fungsi lain

Detail dapat berubah sewaktu-waktu. Pastikan informasi terbaru di situs resmi sebelum melamar.
