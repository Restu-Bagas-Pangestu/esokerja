Tentang lowongan

Durianpay membuka posisi Software Engineer yang awalnya fokus di frontend untuk membangun tool internal dan komponen berbasis design system, lalu bertahap ke backend. Peran ini bekerja sama dengan tim produk, desain, backend, dan infrastruktur.

Kualifikasi

  • S1/S2 (jurusan tidak dibatasi; Informatika/Ilmu Komputer relevan)
  • Pengalaman minimal 2 tahun pengembangan software, terutama frontend
  • Menguasai JavaScript (ES6+), TypeScript, dan Vue.js (CSR & SSR)
  • HTML/CSS, library komponen Vue, dan integrasi RESTful API
  • Terbiasa menulis unit test
